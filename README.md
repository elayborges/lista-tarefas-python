LISTA DE TAREFAS EM PYTHON

Este é um projeto simples de lista de tarefas feito em Python, com o objetivo de praticar conceitos básicos de programação.

FUNCIONALIDADES:
• Adicionar tarefas;
• Listar tarefas;
• Remover tarefas.

TECNOLOGIAS UTILIZADAS:
• Python

OBJETIVO:
Desenvolvi esse projeto como parte dos meus estudos em Análise e Desenvolvimento de Sistemas, com foco em lógica de programação e prática com Python.

COMO EXECUTAR:
1) Baixe o arquivo ou clone o repositório
2) Execute no terminal:
python app.py

APRENDIZADOS
Com esse projeto, consegui praticar:

• Estruturas de repetição;
• Funções;
• Uso de listas;
• Entrada e saída de dados.
